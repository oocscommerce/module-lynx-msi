# Lynx MSI

`oocscommerce/module-lynx-msi`

Multi-Source Inventory for the Lynx storefront.

## Features

- In-store pickup on the Lynx checkout: shoppers search and pick a pickup location
- Stock status of product listings read from MSI
- Disable it on stores without MSI

## Installation

Part of [Lynx](https://docs.oocscommerce.com/lynx/), installed with the metapackage:

```bash
composer require oocscommerce/magento2-lynx-community
```

See [Installation](https://docs.oocscommerce.com/lynx/developer/installation) for the full setup.

## Dependencies
